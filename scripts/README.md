# 本地界面预览

使用项目现有页面、设置和测试用虚构数据预览界面，无需连接 TeslaMate、MQTT 或 Bark。预览使用临时 SQLite，退出后自动清理；只监听本机 `127.0.0.1:8792`，不读取 `.env`。

先安装项目开发依赖与 `web` 前端依赖，再在 `web` 目录运行 `npm run build`。回到项目根目录执行：

```powershell
.\.venv\Scripts\python -m scripts.preview_ui
```

打开 `http://127.0.0.1:8792/preview`，进入预览用会话，可查看历史总览、行程、充电、报告及设置。退出登录后可重新访问此地址进入。预览时钟固定为 2026 年 11 月 1 日，便于比较改版前后的效果；日期筛选请使用 2026 年 9 至 10 月。

地图使用未配置高德 Key 时的轨迹回退样式。显示偏好保存在预览地址自己的浏览器本地存储中，支持主题、强调色、字号、地图与各模块开关。前端改动后重新构建并重启预览服务即可查看。
